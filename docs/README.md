This directory contains information regarding the implementation of the
RDAP Conformance Tool. The target audience for the information captured here
are software developers.

For all others, the User's Manual may be found 
[here](https://icann.github.io/rdap-conformance-tool/).

| [process_flow.md](process_flow.md) | Step-by-step CLI execution flow, exit codes, `RdapWebValidator` |
| [codes.md](codes.md) | Catalogue of test result codes |
| [schema_validator.md](schema_validator.md) / [schema_validator_detailed.md](schema_validator_detailed.md) | JSON schema validation internals |
